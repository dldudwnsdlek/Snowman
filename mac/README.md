# Snowman — 눈 내리는 맥 ❄️

맥의 모든 창과 Dock 위에 눈이 쌓이는 메뉴 막대 앱입니다.
인스타 릴스 「눈 내리는 맥북 만드는 법」의 기능 11가지를 직접 구현했어요.

## 실행

1. `Snowman.app`을 더블클릭합니다. (원하면 `응용 프로그램` 폴더로 옮겨 두세요.)
2. 메뉴 막대 오른쪽에 ❄ 아이콘이 생기면 실행된 거예요. Dock에는 아이콘이 없어요.
3. 처음 실행하면 macOS가 **손쉬운 사용** 권한을 물어봅니다. 허용하면 눈이 Dock 크기에 딱 맞게 쌓여요.
   허용하지 않아도 나머지 기능은 모두 동작합니다. (나중에 메뉴의 `Dock 크기 맞추기 권한 허용…`에서 켤 수 있어요.)

> 직접 빌드한 앱이라 처음 열 때 "확인되지 않은 개발자" 경고가 나오면, Finder에서 앱을 우클릭 → `열기`를 누르세요.

## 기능

| # | 기능 | 사용법 |
|---|---|---|
| 1 | 모든 창 위에 쌓이는 눈 | Finder, Claude 등 모든 창의 윗면에 쌓여요. 앞 창에 가려진 부분은 보이지 않아요. |
| 2 | Dock 위에도 소복이 | Dock이 올라와 있을 때 Dock 크기에 맞춰 쌓여요. 자동 숨김이면 Dock과 함께 숨었다가 다시 나타나요. |
| 3 | 제설차 부르기 (⌘R) | 제설차가 Dock 위 눈을 밀어내요. Dock이 숨어 있으면 화면 아래 눈을 치워요. |
| 4 | 창을 닫으면 우수수 | 닫거나 최소화한 창의 눈이 떨어져 아래에 다시 쌓여요. 창을 세게 흔들어도 털려요. |
| 5 | 굴릴수록 커지는 눈덩이 | 쌓인 눈에 마우스를 올리면 장갑이 나와요. 눌러서 한 줌 뜬 뒤 옆으로 끌면 굴러가며 커지고, 위로 들면 들고 다녀요. |
| 6 | 살아 있는 눈사람 | 숨 쉬고, 눈을 깜빡이고, 커서가 다가오면 손을 흔들어요. 한 번 클릭하면 춤을 춰요. |
| 7 | 쌓으면 눈사람 완성 | 눈덩이를 다른 눈덩이 위에 놓으면 팔 → 눈 → 코 → 입 → 목도리 → 모자 순서로 생겨요. |
| 8 | 눈사람 5종 | 산타 · 비니 · 신사 · 귀마개 · 요정. 모자, 목도리, 표정이 모두 달라요. |
| 9 | 던지면 와장창 | 눈사람을 잡고 휙 던지면 벽에 부딪혀 반대로 튕겨요. 아주 세게 던지면 부서져 눈덩이 두 개로 돌아가요. |
| 10 | 눈 양 조절 | 메뉴 `눈 양`에서 조금 / 보통 / 펑펑. `눈 멈추기`(⌘P)로 잠시 멈출 수도 있어요. |
| 11 | 겨울 배경화면 10종 | `겨울 배경화면 고르기`에서 고르는 즉시 바뀌어요. `원래 배경화면으로`를 누르면 처음 배경화면으로 돌아가요. |

메뉴 단축키(⌘P, ⌘R, ⌘C, ⌘Q)는 ❄ 메뉴가 열려 있을 때만 동작해요. 다른 앱의 복사·인쇄 단축키를 빼앗지 않아요.

## 알아 두면 좋은 점

- 평소 클릭은 그대로 아래 창으로 전달돼요. 쌓인 눈(3pt 이상), 눈덩이, 눈사람 위에서만 앱이 클릭을 받아요.
- 화면을 꽉 채운 창은 메뉴 막대 바로 밑에 눈이 얇게 쌓여요. 메뉴 글자를 가리지 않으려고 높이를 제한했어요.
- 배경화면은 macOS 제약 때문에 지금 보고 있는 데스크톱 공간(Space)에만 적용돼요.
- 배경화면 이미지는 `~/Library/Application Support/Snowman/Wallpapers/`에 저장돼요(약 15MB).
- 앱을 다시 빌드하면 서명이 바뀌어서 손쉬운 사용 권한을 한 번 더 켜야 할 수 있어요.
  (시스템 설정 → 개인정보 보호 및 보안 → 손쉬운 사용에서 Snowman을 지웠다가 다시 추가)
- CPU 사용량: 보통 약 7%, 펑펑 약 13% (M5 Pro 기준).

## 직접 빌드하기

Xcode 없이 Command Line Tools만으로 빌드돼요.

```bash
./build.sh                 # Snowman.app 생성
swift run SnowCoreChecks   # 로직·그림 검사 (151개)
swift run -c release ArtPreview --wallpapers ./preview   # 배경화면 미리보기 PNG
```

```
  WinterArt/       눈사람·제설차·배경화면·아이콘을 코드로 그리는 부분

  ArtPreview/      그림 미리보기 / 아이콘 생성 도구

```
