## Snowman — 눈 내리는 윈도우 ❄️

**설치 방법**
1. 아래 `Snowman-win-x64.zip`을 받아 압축을 풉니다.
2. `Snowman.exe`를 더블클릭합니다. (설치 과정 없음, .NET 따로 설치할 필요 없음)
3. "Windows의 PC 보호" 창이 뜨면 **추가 정보 → 실행**을 누르세요. 서명되지 않은 개인 앱이라 처음 한 번 나오는 경고예요.
4. 화면 오른쪽 아래 알림 영역에 ❄ 아이콘이 생기면 실행된 거예요. 아이콘을 누르면 메뉴가 열려요.

Windows 10 (1809 이상) / Windows 11, 64비트용입니다.
